Pest weather check and weekly advice are working drafts. Yield, harvest, weak patches, radar, winter crop water and the neighbour comparison have first versions. Sensors are a plan. No dates are promised yet.

Pest and disease alerts

A weekly weather check for each plot is now on the pest page, with week-by-week charts and a field-check list. Next: compare it with pest counts in the field before trusting it. Add a leaf-wetness sensor.

Weekly advice

A short weekly note on each plot page: crop stage, pest weather, heavy rain days and dry spells, and checked links to KVK Koraput, IMD and NRRI advice. Next: check it with KVK Koraput.

3 · First version

Yield comparison

1–23 October greenness, this year against last. The Fishing Pond plot looks a little behind, mostly because it was planted later. A fair comparison is possible only after harvest.

A · First version

Harvest heads-up

Weekly check of new photos; rough window about 15 Nov – 5 Dec 2026 (estimate), Temple plot likely first.

B · First version

Weak patches inside a plot

A possible weak patch in the south-west part of the Fishing Pond plot; none in the Temple plot. Next: walk it and look.

C · First version

Radar that sees through clouds

Rough planting dates (±12 days) for both plots, and a check of the road-side strip next to the Panchayat Pond. Next: feed planting dates into the pest check automatically.

D · First version · estimate

Winter crop water

Done as an estimate: how far the Panchayat Pond, already used for the Fishing Pond plot, could stretch to green gram, black gram or mustard, at an assumed 1.5 m depth (range 1–2 m). Re-worked when the pond's open water changes. Next: measure the real depth with a marked pole.

Compare with neighbouring fields

Done: each plot against paddy within 2 km found from space. Fishing Pond plot about the same as its neighbours; Temple plot above them. Next: check some neighbouring fields on the ground.
